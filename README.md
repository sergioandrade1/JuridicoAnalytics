# Juridico Analytics

Painel web estatico de gestao juridica/administrativa. Veja `PRODUCT.md`.

```bash
npm install   # so ferramentas de desenvolvimento
npm run dev   # http://localhost:8080
npm run check # lint + formato + testes
```

Deploy: Netlify publica a raiz do repositorio, sem build. Documentos: `docs/setup.md`, `docs/architecture.md`, `docs/design.md`, `docs/onboarding.md`, `docs/quality.md`.
